📦 XLibre Void Repository

Репозиторий дополнительных пакетов для Void Linux с поддержкой кастомных драйверов и утилит.

Как подключить

echo 'repository=https://sofijacom.github.io/void-package' | sudo tee /etc/xbps.d/99-xlibre-void.conf
sudo xbps-install -S

Доступные пакеты

  • xlibre-xf86-input-evdev
  • xlibre-drm-next (если есть)

🔑 Публичный ключ для проверки.
