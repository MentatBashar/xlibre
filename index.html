📦 XLibre Void Repository

Репозиторий дополнительных пакетов для Void Linux с поддержкой кастомных драйверов и утилит.

Как подключить

printf "repository=https://github.com/xlibre-void/xlibre/releases/latest/download/" | sudo tee /etc/xbps.d/99-repository-xlibre.conf
sudo xbps-install -S

Доступные пакеты

  • xlibre
  • xlibre-xserver (*)

🔑 Публичный ключ для проверки.
